🚀 API Backend – Documentación Rápida

👤 Usuarios

Endpoints para registrar y loguear usuarios.

📌 Registrar usuario

POST /api/users/register

{
  "name": "Juan",
  "last_name": "Pérez",
  "birth_date": "1990-01-01",
  "email": "juan@test.com",
  "password": "123456"
}
📌 Login

POST /api/users/login

{
  "email": "juan@test.com",
  "password": "123456"
}

🛒 Productos

Endpoints para listar, crear y administrar productos.

GET /api/products

GET /api/products/:id

POST /api/products (Admin)

PUT /api/products/:id (Admin)

DELETE /api/products/:id (Admin)

📌 Ejemplo Crear Producto (form-data)
name: "Producto 1"
description: "Descripción"
price: 200
img: (archivo)

🛍 Carrito

Rutas para manejar el carrito del usuario.

POST /api/cart/add

{
  "user_id": 1,
  "product_id": 3,
  "quantity": 2
}

GET /api/cart/:user_id

Devuelve el carrito del usuario.

💳 Checkout

Genera la orden del usuario.

POST /api/cart/checkout

{
  "user_id": 1
}
